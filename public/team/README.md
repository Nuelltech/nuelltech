# Fotos de Perfil dos Cartões de Visita Nuelltech

Coloque aqui as fotos de perfil dos colaboradores.

Exemplo para o Nuno Miguel:
- Ficheiro: `nuno-miguel.jpg` ou `nuno-miguel.png`
- Caminho público: `/team/nuno-miguel.jpg`
- Formato recomendado: Quadrado (ex: 500x500px), JPG ou WebP/PNG de boa resolução.

Se a foto não for encontrada ou ainda não existir, o cartão exibe automaticamente um avatar elegante com as iniciais do colaborador ("NM") com anel gradiente de luz.
